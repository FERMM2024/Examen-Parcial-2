# **App Name**: GameScape

## Core Features:

- Product Catalog: Display a list of video game products, each with an image, title, and price.
- Product Categorization: Categorize products and display categories as filter options. Categories are obtained via a tool that uses generative AI.
- Fuzzy Search: Implement a search bar to filter products by name. User should be able to search with partial or inexact terms, since it incorporates LLM-based vector similarity search
- Responsive Design: Present the products in a responsive grid layout that adapts to different screen sizes.
- AI Assisted Categorization: The products can be easily curated into categories using an AI-powered tool.
- Interactive welcome tour: A brief welcome tour introducing how to filter or search for the right product.

## Style Guidelines:

- Primary color: Deep indigo (#3F51B5), suggestive of a sense of immersion.
- Background color: Very light grey (#F5F5F5) for a clean, non-distracting backdrop.
- Accent color: A muted purple (#9575CD) that complements the primary and adds sophistication.
- Body and headline font: 'Inter' (sans-serif) for a modern, readable experience.
- Use clear and recognizable icons to represent product categories and search actions.
- Employ a clean, card-based layout for products, with clear separation between product information.
- Implement smooth transitions and subtle animations for user interactions, such as filtering and searching.
